# Review a checkout edit

1. Read `orders.py` and show the proposed diff.
2. Ask the user to approve the edit. Check that the file still matches the preview.
3. Apply the reviewed change, then run the check in the example README.
4. Report whether the published `checkout(cart=...)` call still works.

Adapted for the workshop from [TStack’s review skill](https://github.com/tridev-tej/tstack/blob/168a29763169dcd3165d099004fd8f2d46025c6f/skills/review/SKILL.md).
